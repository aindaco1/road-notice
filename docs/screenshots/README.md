# Store screenshots

`1.0-settings.png` is an unedited 1320 × 2868 capture of the 1.0 settings UI on an iPhone 16 Pro Max simulator. The development build uses an iOS 18 deployment override with the installed runtime; the signed distribution build still requires iOS 27. The screenshot shows the actual settings, default-on speed check and bundled 2,695-location database. It does not establish physical background or audio acceptance.

Uploaded to App Store Connect for 1.0 on September 15, 2026 in the 6.9-inch slot. Apple automatically reuses it for the required 6.5-inch display. The uploaded filename is `fine-me-not-1.0-settings.png`; its contents match this source image.

`1.0.3-settings.png` is an unedited iPhone 18 Pro / iOS 27 simulator capture of
version 1.0.3 (11), taken September 16, 2026 at the default text size. It shows the
website-matched icon/wordmark and the existing Settings screen. The same build
was visually checked at the largest accessibility text size with a stacked
header. No deployment-target override is used. This image has not replaced the
historical 1.0 App Store submission screenshot.


`1.0.4-settings.png` shows Road Notice 1.0.4 (12) on the iPhone 18 Pro Max /
iOS 27 simulator at the default text size. It is an unedited 1320 x 2868 PNG,
with the simulator status bar set to 9:41 and a full battery. The app uses the
actual iOS 17 minimum, the new shared icon and wordmark, and 2,701 bundled
camera records. It is the replacement for the rejected submission's screenshot;
it does not establish physical background or audio acceptance.
